# 📦 Inventory Tracker

A simple and efficient **Inventory Management System** built using Python and SQLite. This project helps users manage product records, track stock levels, and calculate the total value of inventory through a menu-driven interface.

## 🚀 Features

* **Add Product:** Add new products with their names, quantities, and prices.
* **View Products:** Display all products stored in the database.
* **Search Product:** Search for a product using its ID.
* **Update Product:** Update product quantities and prices.
* **Delete Product:** Remove products from the inventory.
* **Low Stock Alert:** Identify products with a quantity below 5.
* **Total Inventory Value:** Calculate the total value of all products in stock.
* **Database Storage:** Store product information using SQLite.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Database:** SQLite
* **Libraries:** `sqlite3` (Python standard library)

## 📋 Requirements

* Python 3.x
* No additional Python packages are required.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/sharanyaveeranki-creator/InventoryTracker.git
```

### 2. Navigate to the project directory

```bash
cd InventoryTracker
```

### 3. Run the application

```bash
python inventory.py
```

On Windows, you can also use:

```bash
py inventory.py
```

The SQLite database is created and used by the application.

## 💻 Application Menu

```text
===== INVENTORY TRACKER =====
```

## 🗄️ Database Structure

The application uses an SQLite database to store product information, including:

* Product ID
* Product Name
* Quantity
* Price

## 🎯 Project Objective

The objective of this project is to demonstrate Python programming, database connectivity, CRUD operations (Create, Read, Update, Delete), and basic inventory management.
